# Первичный анализ

## Соревнование
Дано: таблица транзакций, 33 месяца по дням
Таргет: кол-во проданных единиц (item_cnt_day)
Гранулярность - (день х магазин х товар)
Особенность:
1) Отсутствуют нулевые продажи (они не идут в транзакции)
2) Присутствуют отрицательные продажи (возвраты)
3) Присутствуют повторы - один и тот же товар продан в тот же день в том же магазине
4) Из 22170 товаров:
	1) в train нет 363 (но они есть в test)
	2) в test нет 17070 (5010 уникальны)
5) Дубли магазинов: (shop_map = {0: 57, 1: 58, 11: 10})
	1) 10 - 11
	2) 0 - 57
	3) 1 - 58

Задача: провести анализ (магазин х товар) следующего месяца и предсказать кол-во проданных единиц
Метрика: RMSE

## Структура данных на обучение
Test представляет собой таблицу (ИД, магазин, товар) на месяц. Это значит, что транзакции необходимо группировать по месяцам и только потом использовать для обучения
