# GET

## `GET /health`

Проверяет доступность API. Поле `model_loaded` показывает, готов ли сервис принимать запросы на прогноз.

| Код | Результат | Тело ответа |
| --- | --- | --- |
| `200 OK` | Сервис работает, модель загружена. | `{"status":"ok","model_loaded":true}` |
| `200 OK` | Сервис работает, модель ещё не загружена. | `{"status":"ok","model_loaded":false}` |

## `GET /train/{run_id}`

Возвращает состояние запуска обучения по идентификатору, который выдал `POST /train`.

| Код | Результат | Тело ответа |
| --- | --- | --- |
| `200 OK` | Обучение выполняется. | `{"run_id":"abc123","status":"running"}` |
| `200 OK` | Обучение и проверка завершились, новая версия зарегистрирована в MLflow и активирована. | `{"run_id":"abc123","status":"succeeded","model_version":"2"}` |
| `200 OK` | Запуск завершился ошибкой. Если модель уже была загружена, она продолжает обслуживать прогнозы. | `{"run_id":"abc123","status":"failed","error":"Training failed"}` |
| `404 Not Found` | Запуск с таким идентификатором не найден. | `{"detail":"training run not found"}` |

# POST

## `POST /predict`

Возвращает прогноз продаж на целевой месяц для каждой пары `(shop_id, item_id)`. Принимает от 1 до 250 000 пар с неотрицательными целочисленными идентификаторами. Сохраняет порядок и дубликаты.

Пример тела запроса: `{"items":[{"shop_id":1,"item_id":2}]}`.

| Параметр | Описание | Обязательность |
| --- | --- | --- |
| `items` | Массив из 1–250 000 пар магазина и товара. | Да |
| `items[].shop_id` | Неотрицательный целочисленный идентификатор магазина. | Да, для каждой пары |
| `items[].item_id` | Неотрицательный целочисленный идентификатор товара. | Да, для каждой пары |

| Код | Результат | Тело ответа |
| --- | --- | --- |
| `200 OK` | Прогнозы рассчитаны. | `{"predictions":[{"shop_id":1,"item_id":2,"item_cnt_month":3.0}]}` |
| `400 Bad Request` | В запросе есть неизвестные магазины или товары. | `{"detail":{"message":"unknown ids","shop_id":[99],"item_id":[777]}}` |
| `422 Unprocessable Entity` | Тело запроса не прошло валидацию. | `detail` со списком ошибок валидации. |
| `500 Internal Server Error` | Предиктор вернул число прогнозов, отличное от числа входных пар. | `{"detail":"predictor returned wrong length"}` |
| `503 Service Unavailable` | Модель не загружена. | `{"detail":"model is not loaded"}` |

## `POST /train`

Принимает гиперпараметры LightGBM в JSON и запускает обучение в отдельном процессе внутри контейнера. Одновременно выполняется один запуск. Пока он идёт, прогнозы обслуживает текущая модель, если она загружена.

Пример тела запроса: `{"learning_rate":0.05,"num_leaves":31,"n_estimators":500}`.

Передайте `{}`, чтобы обучить модель с параметрами по умолчанию.

| Параметр | Описание | Обязательность |
| --- | --- | --- |
| `learning_rate` | Конечное число больше нуля. Масштабирует вклад каждого нового дерева. По умолчанию `0.05`. | Нет |
| `num_leaves` | Максимальное число листьев в дереве от 2 до 131 072. По умолчанию `84`. | Нет |
| `n_estimators` | Максимальное число итераций бустинга, целое число от 1. По умолчанию `215`. | Нет |

| Код | Результат | Тело ответа |
| --- | --- | --- |
| `202 Accepted` | Запуск принят. По `run_id` можно проверить его состояние через `GET /train/{run_id}`. | `{"run_id":"abc123"}` |
| `409 Conflict` | Обучение уже выполняется. | `{"detail":"training already in progress"}` |
| `422 Unprocessable Entity` | Тело запроса или гиперпараметры не прошли валидацию. | `detail` со списком ошибок валидации. |
